# 🚀 Simple Blog Publication App
A modern full-stack blog platform built with Next.js, Supabase, and Stripe. This project was developed as a training evaluation assignment.
---

## ✨ Features
- **Public & Premium Content:** Free users can view regular blogs, while premium articles are restricted.
- **Stripe Subscription:** Users can subscribe to unlock premium content.
- **Social Login (OAuth):** Secure authentication powered by Supabase.
- **Admin Dashboard:** Content management capabilities for authorized authors.

## 🛠️ Tech Stack
- **Frontend:** Next.js (App Router), Tailwind CSS, TypeScript
- **Backend/Database:** Supabase (PostgreSQL)
- **Payments:** Stripe API
- **Deployment:** Vercel

---

## 🚀 Getting Started

First, run the development server:

```bash
npm run dev
```
Open http://localhost:3000 with your browser to see the result.
